           what is identifier?

> An identifier is a name that we give to a programming element in Python.
 Programming elements can include:

  Variables
  Functions
  Classes
  Objects
  Modules, etc.

  ex. name = "reddy"
  (in this ex. "name" is the identifier )
  > is an identifier because it is the name used to identify the variable.
